# 原始 AI 对话导出说明

## 来源

- 工具：AI 编程会话（DeepSeek Harness）
- 时间：2026-11-02 21:23 至 2026-11-03
- 内容：从 0 构建《答辩预演舱》的真实开发会话
- 导出方式：按时间戳提取「用户原始输入」与「AI 最终回复」，省略工具调用、命令输出和中间推理，保留决策、Bug、修复与验收结论。

## 为什么是 Markdown

该工具没有一键导出完整对话的功能。按赛规“如果 AI 工具不支持导出，可以截图或者录屏”的口径，这里采用等价的文本导出：保留原始措辞、时间顺序和对话双方，不改写成事后总结。

## 文件

- `01-scope.md`：选题、范围收窄、分工确认
- `02-build.md`：材料解析、论点抽取、评分校准
- `03-bugfix.md`：SSE、滚动、构建环境等真实 Bug 与修复

## 说明

- 本项目只使用了这一个 AI 编程工具；以上内容均从该工具的真实会话导出，没有使用 Cursor/Trae 等其他工具。
- 仅保留与项目开发相关的对话；与评审无关的内容已删除。
- 开发以 AI 自动推进为主，用户以阶段目标、验收和关键选择介入；文件按实际发生顺序保留，没有补写用户没有说过的话。
- 完整会话还包含大量工具调用与命令输出，未全部展开；如需更细的某一段，可按提交时间补充导出。
