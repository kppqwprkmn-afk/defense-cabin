# Prompt 链 · 02 材料解析与论点抽取

> 时间：2026-11-02  
> 阶段：RAG / 领域抽取  
> 对应提交：`feat/claim-parser`、`fix/claim-parser`

## 1. 人类输入

```text
不要做通用摘要。把申报书拆成“可质询论点”，每条要有：
- 类型：创新 / 方法 / 数据 / 应用 / 团队 / 承诺
- 证据强度：strong / medium / weak
- 缺口标签：缺基线、缺样本、因果混淆、承诺性指标、无出处、概念堆叠

用规则实现，保证离线可复现；不要依赖大模型。
另外给我一个“材料体检”：章节覆盖、强证据占比、证据密度。
```

## 2. AI 产出

- `domain/text.ts`：按 Markdown/中文标题切章节，再按 620 字切块；中文 unigram + bigram 分词；BM25（k1=1.4, b=0.75）。
- `domain/analyze.ts`：
  - 句子级打分：数字、样本量、基线词、创新词、准确率词分别加权；
  - 缺口检测：`no_baseline / no_sample / causal / promise / no_source / vague / buzzword`；
  - 论点排序：类型加成 + 章节加成（背景降权、方案/数据/成果升权）− 缺口惩罚；
  - 最多 12 条，单一类型最多 4 条；承诺性表述必须保留 1 条（否则最容易被击穿的句子会漏掉）。
- 体检：8 个评审必看板块的覆盖情况 + 强证据占比 + 证据密度。

## 3. 翻车现场

第一次跑示例材料，前端显示：

```text
年 9 月至 10 月，团队在 3 所高校、47 间实验室开展为期 6 周的试点……
```

年份 `2025` 被吃掉了。根因不是模型，而是 `sentences()` 里的清洗正则：

```ts
// 错误：把任意开头数字都当成列表序号
.replace(/^[-•·*\d.\s、]+/, '')
```

于是 `2025 年` 被当成 `2025.` 列表标记剥掉。

## 4. 人工纠偏

```text
年份被吃掉了。清洗规则只应该处理“1–2 位数字 + . 或 、”的列表标记，
不能碰四位数年份。修完后加一条单测，确保 “2025 年” 原样保留。
另外，核心创新句“本项目提出……框架，准确率 92.4%”没有进入前 12，
被四条数据论点挤掉了；把“提出…框架”的权重提上来，并让承诺句强制入榜。
```

## 5. 修复

```diff
- .replace(/^[-•·*\d.\s、]+/, '')
+ .replace(/^[-•·*]\s*/, '')
+ .replace(/^\d{1,2}[.、]\s*/, '')
```

```diff
- const kindBonus = kind === '创新' ? 8 : kind === '数据' ? 9 : ...
+ const kindBonus = kind === '创新' ? 9 : kind === '数据' ? 10 : ...
+ const sectionBonus = /背景|问题定义|现状/.test(section.title) ? -16 : ...
```

```diff
+ // 承诺性表述必须进入质询清单
+ if (!selected.some((c) => c.issues.includes('promise'))) { ... }
```
