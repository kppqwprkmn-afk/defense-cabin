答辩预演舱 · 参赛作品包
========================================

一、先看哪里
1. README.md                 —— 10 分钟复现、架构、API、评审对标
2. SUBMISSION.md             —— 赛规材料对照与提交前自检
3. docs/technical-report.pdf —— 26 页技术文档（≤30 页）
4. video/答辩预演舱-演示视频.mp4 —— 约 5 分 26 秒，1080p
5. docs/prompts/             —— 5 个核心迭代的 Prompt 链
6. screenshots/              —— 首页 / 预检 / 质询 / 报告 / 研发现场 / 移动端

二、怎么跑
需要 Node.js ≥ 20 与 pnpm ≥ 9。

  pnpm install
  pnpm build
  pnpm start
  # 浏览器打开 http://127.0.0.1:8787

无需 API Key、无需数据库、无需 Python。
默认 AI_MODE=mock（确定性离线引擎）；要接真实模型，复制 .env.example 为 .env，
设置 AI_MODE=openai 与 OPENAI_API_KEY 即可。

三、提交前必须由你补的 4 件事
1. 把本目录推送到你的 GitHub / Gitee，仓库设为 Public，提交链接。
2. 在报名系统填写姓名、学校、组别（研究生 / A / B / C）。
   组别必须按学籍选择，选错会被无条件取消资格。
3. 若有 AI 工具的原始对话导出（JSON/HTML/截图），放到 docs/prompts/raw/。
   当前 docs/prompts 是结构化还原，保留了真实指令、报错与修复，但不是逐字导出。
4. 视频旁白目前是 TTS。若赛规要求选手本人讲解，按 docs/demo-video-script.md
   重录旁白并替换音轨（画面无需重录）。

四、作品边界（答辩时主动说明）
- 示例项目“智巡校园”为虚构材料，不涉及任何真实学校数据。
- 评分是风险折算与演练参考，不构成奖项预测。
- Mock 模式是确定性规则导演，不是“假数据占位”；真实 LLM 为可选增强。
- 本作品从 0 编写，未直接包装任何开源项目；依赖均为公开基础库（MIT/Apache）。

五、Git
本目录保留完整 .git 历史（二十余次提交）。查看：

六、如果安装遇到问题
- esbuild 构建脚本被拦截：pnpm approve-builds 勾选 esbuild，或 pnpm rebuild esbuild
- Windows 依赖链接异常：本项目已设置 nodeLinker: hoisted；删除 node_modules 后重装
- 端口占用：PORT=8899 pnpm start
