答辩预演舱 · 文件清单（导师版）
================================================

说明：
- 每个文件名后面直接标注“这是什么、用来干什么”。
- 标 [必看] 的，是 20 分钟内了解作品所需的材料。
- 标 [选看] 的，是技术细节、过程证据或运行文件。
- 标 [源码] 的，是程序实现，供老师抽查。
- 本清单只列最终文件夹内的文件；根目录外的两个 zip 在最后单列。

一、入口与总览（根目录）
------------------------------------------------

00-导师审阅说明.txt
  导师入口。作品一句话、20 分钟审阅顺序、学生与 AI 的分工、需要老师把关的 4 个问题、已知局限。[必看]

README.md
  项目总览。包含 10 分钟复现、目录结构、API、评分口径、测试命令。[必看]

提交说明-最终版.txt
  对外提交材料对照。网盘、作品介绍文档、演示视频、技术文档分别用哪个文件。[选看]

文件清单-导师版.txt
  本文件。所有文件的作用注释。[工具]

SUBMISSION.md
  赛事评分项与仓库内容的对照表。把“过程可复现、场景、AI 使用、实用价值”逐项对应到文件。[选看]

LICENSE
  MIT 许可证。说明代码可公开阅读、复现和引用。[选看]

启动.bat
  Windows 一键启动入口。调用 portable\start.bat，浏览器打开 8799。[运行]

提交历史.txt
  Git 提交历史的纯文本版。断网或不想打开 GitHub 时，可直接看 30 余次提交记录。[选看]

.env.example
  可选真实 LLM 的环境变量示例。默认 mock 模式不需要填写。[选看]

.gitignore
  Git 忽略规则。排除 node_modules、构建产物、本地数据、便携版和提交材料。[工具]

.npmrc
  pnpm 安装参数。Windows 下使用 hoisted 依赖布局，避免 junction 问题。[工具]

package.json
  根工作区脚本。pnpm dev / build / start / test / e2e 的入口。[源码]

pnpm-lock.yaml
  依赖锁定文件。保证老师安装到同一组版本。[工具]

pnpm-workspace.yaml
  monorepo 工作区声明。apps/web、apps/server、packages/shared 三个包。[工具]

tsconfig.base.json
  TypeScript 基础配置。前后端共享严格模式与路径别名。[工具]

.git\
  完整 Git 仓库。30 余次提交，作者均为学生本人账号；每个功能可回溯到对应 diff。[必看-过程证据]

六、源码（apps\ 与 packages\）
------------------------------------------------

apps\server\src\index.ts
  后端入口。启动 Express、加载配置、挂路由、托管前端构建产物。[源码]

apps\server\src\routes.ts
  API 路由。项目创建、上传、预检、开始质询、SSE、报告、Markdown 导出。[源码]

apps\server\src\store.ts
  JSON 数据访问层。projects / sessions / turns / risks / revisions 的读写与原子落盘。[源码]

apps\server\src\report.ts
  报告生成。把会话、风险、修订整理成前端报告和 Markdown。[源码]

apps\server\src\config.ts
  运行配置。端口、AI_MODE（mock/real）、数据目录、上传限制。[源码]

apps\server\src\domain\analyze.ts
  材料解析核心。章节切分、句子清洗、论点抽取、证据强度、七类缺口。[源码]

apps\server\src\domain\analyze.test.ts
  材料解析单测。年份保留、创新句入榜、承诺句兜底、边界情况。[源码]

apps\server\src\domain\text.ts
  中文文本工具。unigram + bigram 分词、标点清洗、句子切分。[源码]

apps\server\src\domain\sample.ts
  示例项目数据。首页“载入示例”使用的虚构材料与预置结果。[源码]

apps\server\src\engine\script.ts
  确定性剧本引擎。标准 27 轮 / 高压 31 轮的评审台词与追问链。[源码]

apps\server\src\engine\orchestrator.ts
  质询编排。开始、推进、落库、SSE 广播、断线重放。[源码]

apps\server\src\engine\scoring.ts
  评分模型。七类缺口映射五维、单维封顶、风险去重、P0/P1/P2 修改项。[源码]

apps\server\src\engine\scoring.test.ts
  评分单测。分数边界、风险去重、修改项排序。[源码]

apps\server\src\engine\llm.ts
  LLM 适配层。mock 模式走本地剧本；真实 API 失败自动回退。[源码]

apps\web\src\main.tsx
  前端入口。挂载 React、路由、全局样式。[源码]

apps\web\src\App.tsx
  路由表。首页、会话页、报告页、研发现场。[源码]

apps\web\src\api.ts
  前端 API 封装。fetch、EventSource、错误处理。[源码]

apps\web\src\pages\Dashboard.tsx

apps\web\src\pages\SessionRoom.tsx

apps\web\src\pages\ReportPage.tsx

apps\web\src\pages\MakingOf.tsx

apps\web\src\components\Shell.tsx

apps\web\src\styles.css
