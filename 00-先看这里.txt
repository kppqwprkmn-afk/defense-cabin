   - README.md
   - docs\technical-report.pdf

二、怎么看网页
完整文件夹版：双击根目录的 启动.bat，浏览器打开 http://127.0.0.1:8799
压缩包版：没有 portable，按 README 用 pnpm 运行，或直接看视频/PDF。

三、赛事系统上传
1. 仓库链接：填上面的 GitHub 地址。
2. 演示视频：完整文件夹版的“提交材料\01-演示视频.mp4”
   或压缩包内的 video\答辩预演舱-演示视频.mp4
3. 技术文档：docs\technical-report.pdf
4. 如系统要求代码包：答辩预演舱-最终提交.zip

四、两个压缩包

答辩预演舱-便携版.zip     免安装 Windows 版，解压后双击 portable\start.bat

五、注意
- 不要双击 apps\web\index.html，那是源码入口，会白屏。
- 提交前补：姓名、学校、组别（研究生/A/B/C）。
- 便携版只适用于 Windows 64 位；Mac/Linux 按 README 用 pnpm 运行。
